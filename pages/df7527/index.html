Prism测试覆盖度量

# 1 前言

一次有意义的尝试，以较小的成本，来尝试数字化的测试覆盖度量是否具备落地应用的可能性。

期望能够以技术驱动测试投入更加有效，降低测试成本。

# 2 设计

先有工具，快速试用验证效果，具备可行性再拓展完善，视发展情况决定如何走下一步，以及与部门公司的平台、体系相结合。

整体架构设计上考虑了后续的应用规模以及与各平台系统的结合。

第一阶段为价值验证，仅开发工具客户端、核心API与工作流任务，不开发WEB界面。

# 2.1 客户端

客户端使用Golang开发命令行工具，二进制发布，根据输入配置参数，全自动完成目标识别、JVM插桩、数据推送到服务端等功能。

计划支持Tomccat以及Jar包直接启动的项目，支持使用Doccker部署以及裸机部署的项目。

当前优先完成Tomcat裸机部署项目的功能支持。

# 2.3 服务端

服务端使用Python开发，使用FastAPI作为Web框架，Celery作为任务调度执行框架，SQLAlchemy作为ORM中间件，数据选型为MySQL5.7。

# 2.4 WEB UI

计划采用Vue3 + ElementPlus开发，暂时不启动，价值验证阶段没有意义。
