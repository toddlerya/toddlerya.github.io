# 背景

有那么个Python第三方库，只有Linux版本，你在Windows没法开发调试，命令行里没有IDE，很痛苦； 有那么些数据，你孱弱的PC性能低下，运行程序龟速，需要在服务器运行，但PC修改，上传服务器很是麻烦，费时费力，感觉自己笨笨的； 其实付费版的PyCharm很强大，稍加配置，即可突破这种困境，且听我缓缓道来。

# 环境检查

服务器Python环境可以用Docker创建，可以参见此文《使用Docker部署Python开发调试运行环境》的第七章：“使用定制的镜像启动容器”。

  1. 确保你的PyCharm是Profession版，社区免费版没有这个功能哦；
  2. 确保Linux服务器可以ssh登陆；
  3. 确保Linux服务器有所需的Python运行环境，查找好所需的Python解释器路径备用

# 注意事项

找到正确的Python解释器路径

服务器通常有多个Python运行环境，可以使用whereis命令查看

root@a6c92ff0463e:~# whereis python
python: /usr/bin/python3.7m /usr/bin/python3.7 /usr/bin/python2.7 /usr/bin/python /usr/lib/python3.7 /usr/lib/python2.7 /etc/python3.7 /etc/python2.7 /etc/python /usr/local/bin/python /usr/local/bin/python3.7-config /usr/local/bin/python3.7m-config /usr/local/bin/python3.7m /usr/local/bin/python3.7 /usr/local/lib/python3.7 /usr/local/lib/python2.7 /usr/share/python /usr/share/man/man1/python.1.gz

那么多Python运行环境，哪个是我们需要的？需要根据文件名排查下，然后测试下：

root@a6c92ff0463e:~# python -V
Python 3.7.7
root@a6c92ff0463e:~# /usr/local/bin/python3.7m -V
Python 3.7.7
root@a6c92ff0463e:~# /usr/bin/python3.7m -V
Python 3.7.3

请务必确认好自己所需的是哪个，我用的是Python3.7.7，因此Python解释器路径为：/usr/local/bin/python3.7m

请记好这个路径，后边配置要用到。
