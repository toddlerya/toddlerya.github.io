ASR评估指标

# ASR评估指标

ASR - Automatic Speech Recognizer 自动语音识别程序是一种将人的语音转换为文本的程序。

# 公式因子注解

下文将会用到如下因子进行公式计算，此处说明。

# S

S - Substitution为替换的字数

举个例子：你好呀被识别为你好丫，此时S = 1

# D

D- Deletion为删除的字数

举个例子：你好呀被识别为你好，此时D = 1

# I

I - Insertion为插入的字数

举个例子：你好呀被识别为你们好呀，此时I = 1

# C

C - Correction正确的字数

举个例子，你好呀被识别为你好呀，此时C = 3

# N

N - 涉及到的字数，N = S + D + C

需要注意的是，这并不等于原句总字数或识别结果字数。

# 句错误率（SER）

SER - Sentence Error Rate，识别错误的句子个数除以句子总个数，即为 SER。

# 计算公式：

$$ SER = \frac {错误句数} {总句数} \times 100% $$

# 句正确率（S.Corr）

S.Corr - Setence Correct Rate，识别正确的句子个数除以总的句子个数，即为S.Corr。

# 计算公式：

$$ S.Corr = 1 - SER = \frac {句正确数} {总句数} \times 100% $$

# 字错误率（WER/CER）

WER - Word Error Rate，词错率，一般为英文，其语句最小单位是单词，因此等同于字错率；

CER - Character Error Rate，字符错误率，一般为中文，中文的最小单位为字符。

# 计算公式：

$$ WER/CER = \frac {(S + D + I)} {N} = \frac {(S + D + I)} {(S + D + C)} = \frac {(替换 + 删除 + 插入)} {(替换 + 删除 + 正确)} \times 100% $$

# 字准确率（W.Acc）

W.Acc - Word Accuracy，就是1-WER的结果

# 计算公式：

$$ W.Acc = 1 - WER(or\ CER) = \frac {(N - D -S - I)} {N} = \frac {(C - I)} {(S + D + C)} \times 100% $$

# 字正确率（W.Corr）

W.Corr - Word Correct Rate，字正确率，通常说某ASR识别率达到97%，就是指的字正确率，计算中忽略了插入的字数。

# 计算公式：

$$ W.Corr = \frac {(N - D - S)} {N} = \frac {C} {(S + D + C)} \times 100% $$
