Habor-轻量化容器服务自动部署工具

# 1 需求分析

2022年应公司部门发展需要，开始着手建设性能测试工具平台，我们的主力开发语言依然是Python，既然使用Python，就面临一个部署的老大难问题。

在公司大力推广FX平台进行容器化改造的背景下，我们的测试工具应向公司技术栈看齐，使用Docker技术进行发布和部署。

选择Docker的优势够多，虽然在实际应用时有一些小困难，但与其带来的收益相比，不值一提。

# 1.1 Docker技术发布和部署的优势

  1. Docker的镜像提供了除内核外完整的运行时环境，确保了应用运行环境一致性，从而不会再出现“这段代码在我机器上没问题啊”这类问题；——一致的运行环境
  2. 可以做到秒级、甚至毫秒级的启动时间。大大的节约了开发、测试、部署的时间。——更快速的启动时间
  3. 避免公用的服务器，资源会容易受到其他用户的影响。——隔离性
  4. 可以很轻易的将在一个平台上运行的应用，迁移到另一个平台上，而不用担心运行环境的变化导致应用无法正常运行的情况。——迁移方便
  5. 使用Docker可以通过定制应用镜像来实现持续集成、持续交付、部署。——持续交付和部署

关于Docker的更多介绍可以查看 《Hello Docker》 (opens new window)

# 1.2 一点点小困难

  1. 不是所有服务器都有Docker运行环境；
  2. 没有外网的离线环境如何简单快速的安装Docker服务？
  3. 不是所有服务器都能安装Docker，对内核版本有要求，Linux内核版本要大于等于3.10；

我认为随着时间的推移，老版本的Linux系统会逐步被淘汰升级，Linux内核版本低这个问题会自然消失。

离线环境如何安装Docker服务，我们可以给出优雅的解决方案。

# 2 Harbor的目标

Harbor的目标是消灭冗长的安装文档，力求安装文档只有一页纸的内容。

# 2.1 一分钟部署Docker服务

Docker是可以二进制部署的，但部署操作步骤较多，可以查看此文了解具体过程：《二进制文件安装Docker指南》 (opens new window)

此外我们还要安装Docker-compose服务用于容器编排。

阅读安装文档，手工进行这些操作预估耗时至少要15分钟，我们的目标，1分钟，2个命令完成安装docker和docker-compose服务的安装。

# 2.2 五分钟部署工具应用【开发设计中】

通过简单的配置文件，只需配置下部署环境的IP以及工具服务的端口，1个命令即可启动所需的测试工具服务。
