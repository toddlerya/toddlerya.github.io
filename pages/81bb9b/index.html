# 1 安装

提示

  • 使用Python3.7.7版本进行开发和运行；
  • 使用PypiManager (opens new window)作为pip源；

# 1.1 新建虚拟环境

F:\ait_db_manager_test>pip install -U virtualenv
F:\ait_db_manager_test>virtualenv venv
F:\ait_db_manager_test>venv\Scripts\activate
(venv) F:\ait_db_manager_test>

# 2.5 数据结构解读

笔记

我们以AnnAudioVoicePrint标注数据为例进行讲解。

数据结构定义，是遵循JSONSchema规范编写的，关于JSONSchema的语法说明可以查看《JSONSchema常用关键字语法手册》学习理解。

# 2.5.1 要点

数据结构主要分为以下就几个核心节点：

  • data_source【必选】-- 数据源信息
  • equipment【可选】-- 设备信息
  • identity 【 可选】-- 数据对象人员身份信息
  • file_name【必选】-- 实体对象文件名
  • 标注数据私有字段
