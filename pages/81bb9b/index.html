# 1 安装

TIP

  • 使用Python3.7.7版本进行开发和运行；
  • 使用PypiManager (opens new window)作为pip源；

# 1.1 新建虚拟环境

F:\ait_db_manager_test>pip install -U virtualenv
F:\ait_db_manager_test>virtualenv venv
F:\ait_db_manager_test>venv\Scripts\activate
(venv) F:\ait_db_manager_test>

当看到(venv)时即说明虚拟环境已经激活。

# 1.2 安装AITDBClient

(venv) F:\ait_db_manager_test>pip install -U AITDBClient

# 1.3 验证是否安装成功

(venv) F:\ait_db_manager_test>aitdbclient --version
aitdbclient, version 1.9.0

正常显示版本号说明安装成功。

# 2.6 构造JSON LINE数据文件

将现有的各种类型的标注数据，根据2.5小节的数据结构定义，逐条构造出JSON数据，存储为JSON LINE文件，可以使用AITUtils的AITUtils.file.save_dict2jl (opens new window)方法。

要求构造的JSON LINE文件命名要与已支持的标注数据的名称相同，比如：

# 名称: AnnAudioVoicePrint
# 数据结构定义:
{"title": "AnnAudioVoicePrint", "description": "音频标注-声纹信息数据结构定义", "type": "object", "properties": {"data_source": {"title": "Data Source", "description": 
......
"required": ["gender"]}}}
# 示例数据:
{"data_source": {"category": "音频", "cn_name": "声纹数据_烽火测试部录制", "en_name": "voiceprint_fiberhome_tester", "description": "2021年5月声纹录制数据"}, "equipment": {"cn_name": "C270", "en_name": "C270", "manufacturer": "罗技", "category": "网络摄像头"}, "identity": {"gender": "男性", "person_name": "郭群", "employee_number": "X2590"}, "file_name": "X2590_郭群_C270_2021-04-13#19-04-00_4f94097cb855c2bb20301ba77c71698a.wav", "teleprompter_text": "二幺三九四八七零", "pronounce_text": "21394870", "normalized_text": "21394870", "background_noise": 36}

那么JSON LINE文件名应该为AnnAudioVoicePrint.jl
