Pypi Manager

# 需求背景

公司没有持续更新的内网没有Pip源，恰巧测试部的主力开发语言又是Python，相关Python开发者各自去外网下载python安装包传入内网，重复劳动。

我们应该反思下，是不是我们的工作方式需要改进？

是的，我们应该降低这种工作中的“偶然复杂度”，使用合理的方式方法提高生产效率。

  • 建设内网Pip源

# 愿景目标

人人为我，我为人人，共建共享，饮水思源。

不让同一个python包经过光闸传输第二次。

# 用户群体

测试开发工程师、业务测试工程师、业务开发、工程师、算法工程师、数据工程师等所有Python开发者。

# 设计理念

# 吸取前车之鉴，避免重蹈覆辙

以往公司内网搭建的Pip源都存在一个致命问题：更新维护问题，缺少运营规则，严重依赖个人或团队热情更新pip源，效果甚微，热情燃尽，pip源就废弃了。

我们决定采用**“共建共享，饮水思源”**的指导思想，来盘活pip源的更新问题，通过记录贡献排名来激励所有志同道合的同学共同维护pip源的更新。

用户至上，零上手成本

以往的pip源服务在使用上存在如下弊端：

  • 只是一个简单的包的索引页面，UI简陋，搜索困难，不便于查看浏览；
  • pip客户端配置复杂，需要阅读文档，手动配置，心智成本高；
  • pip源更新依赖登录服务器通过FTP上传，操作复杂，仅管理员有权限，没有建立有效的分享贡献渠道；
  • 使用命令行发布python包学习成本太高，无人使用。

我们的改进策略如下：

  • 提供简单易用的UI交互，智能的搜索体验，每个搜索结果都能看到贡献者，时时刻刻提醒用户“饮水思源”；
  • pip客户端配置智能化、简单化，只需一键执行配置工具，智能适配Windows平台和Linux平台，智能识别pip版本完成配置，心智成本为零；
  • 建立有效的用户分享贡献渠道和激励机制，只需工号即可认证登录，分享上传；
  • 上传控件支持拖拽上传，简单易用，零学习成本。
